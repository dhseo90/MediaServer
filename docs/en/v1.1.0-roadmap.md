# v1.1.0 Roadmap

Detailed Korean roadmap: [../v1.1.0-roadmap.md](../v1.1.0-roadmap.md)

This page mirrors the product boundary for English readers. If another
English document is ambiguous, the Korean roadmap remains the source of truth.

## Direction

```text
Live Operations / ONVIF Onboarding / Live VA Events
```

Media Server remains a live media relay and live video analytics event engine.
v1.1.0 does not turn it into a VMS, NVR, long-term recorder, playback/search
product, or ONVIF Profile G recorder.

## Included

- Live source discovery and import
- ONVIF-assisted live source onboarding
- Live RTSP/WebRTC relay
- Live VA overlay, metadata, and events
- Event delivery through Event POST, WebRTC DataChannel, SSE, and WebSocket
- Operator source health, reconnect, stale, and offline summaries
- Sanitized client live/dashboard state
- Recent state built around short event context and runtime metadata

## Excluded

- Long-term recording, MP4 muxing, video archive, playback timeline, and video search
- NVR/VMS-style recording management
- ONVIF Profile G recording/replay
- ONVIF conformant server, recorder, or replay service
- Recorded evidence as the primary integration contract
- UI for deleting or retaining evidence originals as long-term storage

EventRecord, snapshot, and clip frame bundle hooks may remain as default-off
operations aids or debug/developer helpers. They are short event evidence, not
the central v1.1.0 product message.

## ONVIF Direction

The v1.1.0 ONVIF goal is camera import, not ONVIF server conformance.

- Use: `ONVIF camera import`, `ONVIF-assisted live source onboarding`
- Avoid: `ONVIF conformant server`, `ONVIF Profile G recorder`, `full ONVIF VMS`

Profile direction:

- Profile T is the preferred direction for new live streaming integrations.
- Profile S devices are best-effort import targets for field compatibility.
- Profile M is a research item for live analytics metadata/event export.
- Profile G is outside v1.1.0 scope.

Close-out status:

- Done as prerequisite step 2/6 at the fixture/import-draft/API/UI smoke boundary.
- Real network discovery, SOAP probing, credential persistence, and origin metadata migration are field-integration extensions, not RC blockers.

## alpha.1 Exit Criteria

- Status: Done as prerequisite step 1/6 in the 2026-05-12 close-out.
- RC stabilization should not rerun the live-only boundary phase.
- README and backlog describe v1.1.0 as a live-only target.
- Korean and English docs agree on included and excluded scope.
- MP4 recorder, VMS/NVR, playback/search, and Profile G do not read like v1.1.0 work.
- EventRecord, snapshot, and clip are described only as short event evidence or diagnostics helpers.
