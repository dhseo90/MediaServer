# S11 I30 원인 구분·집중 재검증

독자: v4.1.0 검증·릴리즈 담당자. 수명: B10 및 실패 이력 보존. 정책은 AGENTS.md,
개별 실행 정의는 중앙 테스트 기록 B10-U03/U04와 기존 V410-S06-I30이다.

## 결론·범위

실제 Chrome 152.0.7977.83 / Playwright 1.62.1에서 native 재생·일시정지·탐색을
통과했다. 제품 코드는 변경하지 않았다. 이전 인앱 renderer exit5의 내부 원인은
여전히 미확정이며, 이 결과를 그 브라우저 충돌 수정으로 표현하지 않는다.
기존 424개 검사와 같은 native 브라우저 경로를 사용한 fallback을 명시한다.

메인이 실행 전 검토에서 화면에 없는 ID를 찾는 초안과 느슨한 탐색 판정·실패
보존 누락을 발견해 회수했다. 독립 C++ seed와 실제 timeline 응답을 정확히
대조한 뒤 해당 DOM 행을 선택하도록 보완했다. 새 계정은 메모리 전달 후 실제
login form을 조작했다. 차단됐던 이전 자격증명 파일을 열지 않았다.

## 증거·정리

[3회 보존 증거](b10-i30-evidence.tar.xz), [원출력](b10-i30.log)을 보존한다.
각 run의 결과·trace·network/console·redacted server log·fixture oracle·
source/build/browser hash와 최종 3 action PNG가 포함된다. 실패 두 회의 중복 PNG와
최종 중복 final.png는 보존하지 않는다. 따라서 실패 회차의 부분 PASS를 실제 UI
재사용 증거로 승격하지 않는다. 첫 두 회의 실패 원인·측정값·전수 결과는 유지한다.
압축본은 3,876,268B, SHA256 `6c934d19aded3c72cc5f59feced14e507bfff6ed4dadbb13b6a9736d7df61a65`다.
36개 보존 파일을 archive에서 읽어 원본과 byte 대조한 뒤 임시 원본 세 개를 제거했다.
실행 시간은 순서대로 17,708ms / 17,283ms / 17,613ms. 토큰 start/end/consumed는
전용 집계 미제공으로 미집계, source는 실행 원출력·provenance다.
