# LP15 4단계 비용 검사와 메모리 중단

LP16 보존정정: 참조 raw artifact가 RAW_JSON_LINE 가역표기이면 첫 안내행을 제외하고 JSON문자열을원문행으로복원한뒤 time후미를결합한다. 기존wrapper SHA와원래실패이력은유지한다. wrapper RSS를fixture한도로직접판정한결론은중앙LP16에서측정대상불일치로정정/보류했다.

source HEAD=e9bdde5a; 기존 AVC미커밋 및 비용runner의 Bash3/exit보완 포함. 실제앱 미실행. token start/end/consumed=미집계(실측수단없음).

첫 compaction은 빈배열 nounset 오류로 검사미실행인데 EXIT trap이0을보고했다. 실제판정FAIL. 동일단계에서 prefix=(env),본문완료표식없는EXIT0→1 보완. guard자체검사 normal0/explicit17/unbound1 각PASS, bash-n exit0. 제품/시간상한 변경없음.
