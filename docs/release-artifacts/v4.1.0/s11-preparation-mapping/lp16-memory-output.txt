=== 측정 의미와 실행 경계 ===
macOS만 지원/검증. 자기 current는 mach_task_basic_info.resident_size, 자기 peak는 getrusage(RUSAGE_SELF).ru_maxrss(bytes). peak는 프로세스 누적 high-water이며 구간 할당량/누수 지표가 아니다.
compiler는 단일 CXX invocation와 하위 compiler의 time 관측이며 TU별 PID 전수 측정은 아니다. fixture는 직접 check 프로세스 time과자기단계관측을 별도보존한다. 전체 wrapper/compiler 값을 fixture512MiB 판정에 혼합하지 않는다.
fixture cap판정은 유효한 자기peak/timepeak 중 큰 값. 정확일치 강제하지 않으며 current>peak도자동거부하지 않는다. 28개 exact단계·sources·schema 전수없음/누락/역행/잘못된값은 unknown으로 거부한다. cap초과에도 실제 exit와 측정값을 보존한다.
고정 stage enum: 0 InputBefore / 1 InputAfter / 2 SourceBefore / 3 SourceAfter / 4 StoreBefore / 5 StoreAfter / 6 CommitBefore / 7 CommitAfter / 8 SnapshotBefore / 9 SnapshotAfter / 10 CheckpointBefore / 11 CheckpointAfter / 12 StoreReleased / 13 SqliteOpenBefore / 14 SqliteOpenAfter / 15 SqliteReleased / 16 JsonlOpenBefore / 17 JsonlOpenAfter / 18 JsonlReleased / 19 Finish.
Finish는 return 직전이며 input/originals/outputs 등main 지역fixture 자료는 여전히 생존한다. StoreReleased·각재openReleased는 해당catalog/journal 소멸후지만 fixture 기대자료는유지한다. Snapshot은 기존수명대로CP까지생존하며 측정때문에해제시점을바꾸지않았다.
기존173+계측1 oracle/명시최적화없음/60초compile/180초runtime/512MiB disk/2MiB출력 유지. 기존Bash3 env prefix·fc_completed EXIT보완 보존. process group은 bounded가소유하고memory_phase/time은그룹상속.
