# LP28 frozen candidate 독립 소스 결속 검토

독자: 후보 승인 담당자. Lifecycle: 이 frozen candidate에 대한 거절/범위 한정 판정 artifact. AGENTS.md 또는 제품 계약을 대체하지 않는다.

## 판정

- 전체 판정: **거절**. 307개 변경 행 중 37개 기각, 270개는 selected source-flow/readback 결속 범위에 한정하여 인정한다.
- 679개 strict 승계는 입력의 기계 동등 분류이며 이번 담당자가 679행을 다시 독립 승인했다는 뜻이 아니다.
- requiredOutcome 전체 실행, 실제 UI, 영상 품질, 30분/120분, 제품/릴리즈 PASS는 판정하지 않았다. CSS·HTML·schema·false boundary 등 부분 검사의 실제 의미와 한계를 각 행에 적었다.
- 승인 원장 producer는 실행하지 않았다. decisions의 verdict=rejected 및 37 rejected는 정상적으로 승인 생성을 차단해야 한다. 이를 approved로 바꾸어 우회하면 안 된다.

## 독립성 및 방법

이 담당자는 앞선 LP28 locator validator 구현에 참여했다. 메인이 frozen candidate 생성 및 33개 proof 재연결을 수행했다. 이번 검토 중 저장소 파일 수정·후보 생성·approval 생성·테스트·네트워크/브라우저 실행은 하지 않았다. 도구 작성자와 완전히 분리된 제3자 검토라고 주장하지 않는다.

307행 각각의 요구, dispatch/action/state/readback, evidenceMode를 대조했다. 공통 Start 변경은 동일 함수 diff를 그룹으로 읽고 각 행의 route/guard/직렬화/관측 의미를 분리했다. 특이 분기는 현재 함수 본문·검사 전후값/호출을 추가로 읽었다. 모든 파일 전문을 다시 읽은 전수 제품 감사는 아니다. 별칭 이름·hash 동등성만으로 승인하지 않았다. 공통 변경 286행을 286개 독립 제품 기능 PASS로 계산하지 않는다.

공통 Start의 신규 진단은 request parse/handler/send 시각·상태 계측이며 이번 비교에서 route 판정·응답값 자체 교체는 확인되지 않았다. RTSP compatibility 추가, 녹화 증거 전달, unknown-time HTML/CSS, 종료 수명 변경은 기존 기능 전체 결과와 별개의 변경임을 유지한다. 관련 원장·제품 성능/동작 재검증은 메인의 증거 판정 대상이다.
