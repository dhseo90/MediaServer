# Media Server v4.3.0

v4.3.0 개발 소스는 녹화 이력·검색 자원 수명을 개선하고, 로컬 모델을 사용하는 한국어·영어
영상 유사도 검색을 추가합니다. 로컬 릴리즈 검증 묶음을 통과했으며 아직 공개된 릴리즈는 아닙니다.

## 주요 변경

- 누적 예약 identity의 중복 상주량을 줄이고, 만료된 검색 snapshot과 예약 중 검색 갱신 비용을 개선했습니다.
- 선택 설정으로 Google SigLIP2를 사용해 확정 녹화의 대표 프레임과 원본 연결이 검증된 이벤트 스냅샷을 색인합니다.
- Ops의 장면 설명·채널·시간·유사도 필터로 검색하고, 현재 권한과 원본을 확인한 뒤 해당 재생 시점으로 이동합니다.
- worker·게시 세대·문서 수·추론 동시성을 제한합니다. 확정된 미지원 codec/해상도는 제외하고,
  무결성·시간 초과 오류는 실패로 표시하여 부분 색인을 정상 완료로 게시하지 않습니다.

## 지원 범위와 제한

기능은 기본 비활성입니다. 별도 준비한 로컬 모델·토크나이저와 빌드 의존성이 필요하며
제품 요청에서 모델을 자동 다운로드하거나 외부 임베딩 서비스를 호출하지 않습니다.
기존 V1·원본 증거가 없는 파일/스냅샷은 검색되지 않습니다. 모델 점수는 사건 발생·동일 인물의 증거가 아닙니다.
검색 간격 사이의 장면을 모두 포착하거나 임의 codec·운영 규모·무기한 보관을 보장하지 않습니다.

설정과 API는 [설정 참조](config-reference.md), UI 사용은 [UI 가이드](ui-guide.md),
유한한 개발 규모·메모리·동시성 한도는 [개발 계약](superpowers/specs/2026-10-04-v430-visual-vector-search-design.md)을 따릅니다.
모델·미디어·런타임 바이너리를 포함하지 않는 source-only 배포 정책을 유지합니다.

## 검증 상태

개발 중 직접 검사와 focused 실제 UI 재검증은 [개발 기록](history/README.md#v430-개발과-로컬-검증)에
최초 실패와 재검증을 함께 보존했습니다. 이후 `b41fcff9`에서 실행한
[`./test_release.sh` 결과](history/README.md#v430-개발과-로컬-검증)는
안정화·30분·120분·Policy v4 실제 UI 424건과 실행 자원 정리에 합격했습니다.
공통 서버 장시간 검증은 SigLIP2 검색·색인의 장시간 혼합 부하 증거가 아니며,
424건의 기존 UI 묶음과 신규 검색의 개발 중 직접 UI 검증은 구분합니다.
외부 TURN 검증은 실행하지 않았습니다. 실행 기록은 Git 원본 대조 후 현행 트리에서 정리했습니다. required CI와 공개 절차는 남아 있습니다.
