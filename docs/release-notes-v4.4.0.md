# Media Server v4.4.0

v4.4.0은 검색 결과의 출처와 대표 프레임, 연결된 이벤트 영상을 원본 녹화와
분리해 보존하는 Evidence Package를 추가하는 개발 버전입니다. 구현과 단기 검증을 마쳤으며 릴리즈 검증은 남아 있습니다.

## 변경 범위

- 구조화·영상 유사도 검색의 서버 소유 결과에서 명시적으로 증거를 보존합니다.
- 정확한 원본 sample의 RGB와 무손실 PNG, source generation·시간·checksum을 연결합니다.
- 녹화·clip·frame·track·event·observation 참조와 누락·삭제·미지원 상태를 불변 manifest에 남깁니다.
- 원본 순환 보존과 분리된 패키지 파일을 원자 게시하고, 재시작 때 무결성을 확인해 읽습니다.
- Ops에서 보존 목록·상세·이미지·clip을 조회합니다. 생성과 조회에 현재 역할·채널 scope를 적용합니다.

## 지원 경계

기본 비활성인 `MEDIA_SERVER_EVIDENCE_ENABLED=1`로 선택 활성화합니다. 녹화도 활성화해야 합니다.
정확한 프레임 추출은 기존 V2 원본 sample 증명과 decoder의 지원 범위를 따릅니다.
최대 8개 대표 프레임이며 전체 프레임 또는 전체 원본 영상의 보존을 뜻하지 않습니다.
clip이 연결되지 않은 결과는 clip 비해당, 존재해야 할 자료의 누락·삭제·미지원은 부분 보존입니다.
무결성 실패와 timeout은 정상적인 누락 성공으로 처리하지 않습니다.

패키지는 `evidence-hold` 등급으로 자동 삭제하지 않습니다. 저장 상한 2GiB/4096개,
개별 패키지 256MiB와 디스크 reserve를 초과하면 새 생성을 거부합니다.
원본 삭제 후 보존 파일의 독립 조회와 원본 자체의 재생 가능 상태는 별개입니다.
hash는 출처 서명이나 법적 진정성 보증이 아니며, VLM 판단·교차 카메라 동일성·자연어 검색은 추가하지 않습니다.

설정·API는 [설정 참조](config-reference.md#증거-패키지-api-v440),
화면은 [UI 가이드](ui-guide.md#증거-패키지-v440),
구현 계약·완료 기대값은 [개발 계약](superpowers/specs/2026-10-04-v440-evidence-package-design.md)과
[테스트 정의](project-feature-test-inventory.md#v440-증거-패키지)를 따릅니다.

## 검증과 공개 상태

[개발 검증 기록](release-artifacts/v4.4.0/development/README.md)에 빌드·실제 프레임/클립 보존·
활성/비활성 HTTP·실제 로컬 모델·UI 상태·변경 영역 브라우저 확인과 최초 실패/재검증을 남겼습니다.
장시간 부하와 실제 UI 풀테스트를 대신하는 결과가 아닙니다.

릴리즈 안정화 묶음·30분·실제 UI 풀테스트와 120분 필요성 판정/승인,
승인된 독립 검토·required CI·기록 보존/정리·PR/병합·서명 태그·공개·브랜치 삭제는 남아 있습니다.
기존 버전의 PASS나 공개 관측을 이번 버전의 결과로 사용하지 않습니다.
