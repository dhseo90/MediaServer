# v3.9.0 Policy v4 UI Evidence Transition Implementation Plan

대상 독자는 MediaServer의 UI 테스트 정책, 자동화 runner, release evidence를 유지보수하는
개발자 및 자동화 에이전트입니다. 이 문서는 `V390-ADD1-12` 구현 기간에만 사용하는
실행 계획이며, `AGENTS.md`와 `docs/development-backlog.md`의 권한·완료 기준을
대체하지 않습니다.

**Goal:** `AGENTS.md`의 “인앱 브라우저 직접 조작만 UI 풀테스트 evidence” 규칙과
v3.9 native visible-DOM 자동화의 실제 조작 evidence 사이 충돌을 해소하고, 자동화가
개별 수동 UI case를 대체할 수 있는 Policy v4 기준과 전체 UI 풀테스트 PASS 경계를
기계 검증 가능한 정책으로 고정합니다.

**Architecture:** 테스트 영역은 안정화/30분/120분/UI 네 가지를 유지합니다. UI 영역
안에서 evidence mode만 `direct-browser`, `qualified-native-automation`, `hybrid`로
구분합니다. 자동화 동등성은 suite가 아니라 exact case 단위로 판정하고, 전체 suite는
모든 exact test ID와 시각/반응형/role/security 교차 항목이 닫혀야 PASS입니다. 기존
wrapper/static/screenshot-only/fixture/fallback evidence는 보조 evidence로 남깁니다.

**Tech stack:** Node.js ESM, `server.sh`, JSON policy fixture, Markdown policy/evidence,
기존 v3.9 native visible-DOM summary와 exact-ID coverage matrix.

## Task 2 — Policy v4 대체 evidence 계약

- [x] 네 테스트 영역을 유지하고 UI evidence mode만 세 가지로 구분합니다.
- [x] native browser, fallback=false, manualIntervention=false, exact route/control/action,
  pre/action/post/forbidden state, role/viewport/theme, screenshot/trace/video/console/server log,
  cleanup, 재현 정보 조건을 모두 만족한 case만 `automation-equivalent-pass`로 인정합니다.
- [x] raw JSON/API-only, static/one-shot wrapper, fixture, screenshot-only, hidden/source marker,
  artifact 누락, stale/unbound evidence는 자동화 동등 evidence에서 제외합니다.
- [x] video/overlay/crop/visual quality/accessibility처럼 DOM assertion만으로 닫히지 않는
  항목은 direct 또는 명시적 specialized visual evidence가 필요한 hybrid로 남깁니다.
