# v3.9.0 (17) Development 15~18 Implementation Plan

대상 독자는 v3.9.0 (17)의 개발 항목 15~18을 순서대로 구현·검증하는 개발
에이전트입니다. 이 문서는 이번 작업의 실행 계획이며 roadmap 상태의 source-of-truth는
`docs/development-backlog.md`, 기능/테스트 정의의 source-of-truth는
`docs/project-feature-test-inventory.md`와 `docs/release-test-records.md`입니다.

**Goal:** VLM incident-to-rule provenance를 rule 저장까지 보존하고, v3.9 보류 기능의
owner decision과 구조 안정화 착수 조건을 확정하며, 외부 실기기 부재 field smoke를
실제 PASS로 오인하지 않는 명시적 미실행 결정으로 종료합니다.

**Architecture:** 15번만 기존 optional rule document에 서버 검증형 `vlmProvenance`
metadata를 추가합니다. 16~18번은 제품 write/media 동작을 만들지 않고 기존 inventory,
handoff plan, field evidence 경계를 승인·착수·미실행 결정으로 닫습니다.
