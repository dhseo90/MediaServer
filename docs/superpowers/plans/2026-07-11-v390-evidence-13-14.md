# v3.9.0 Evidence 13~14 Implementation Plan

대상 독자는 v3.9.0 Step 26 final evidence를 구현·재감사하는 개발 에이전트입니다.
이 문서는 13~14 개발 동안만 유지하는 실행 계획이며, roadmap 상태의 source-of-truth는
`docs/development-backlog.md`, 테스트 결과의 source-of-truth는
`docs/release-test-records.md`입니다.

**Goal:** 최종 acceptance evidence에서 중복 screenshot, 영상 placeholder, 상수형 cleanup
판정을 제거하고 source commit SHA·실행 명령·첫 실패 지점을 보존한 뒤 독립 bundle을
재실행해 cleanup까지 검증합니다.

**Architecture:** 제품 API/Auth/media/UI 동작은 바꾸지 않습니다. v3.9 UI/longrun/acceptance
runner와 replay verifier만 보강하고, 최종 bundle root는 실행 전에 안전하게 교체합니다.
UI screenshot은 content hash로 중복 파일을 제거하되 case reference는 canonical artifact를
가리키게 합니다. 지원하지 않는 video는 빈 artifact와 명시적 not-captured reason으로 남기며
placeholder 파일을 만들지 않습니다. cleanup은 child summary, port, temp path의 실제 관측값으로
계산합니다.
