# v3.9.0 REVIEW4 50~62 Implementation Plan

> 독자: v3.9.0 REVIEW4 50~62를 순차 구현·검증하는 개발자와 자동화 에이전트.
> lifecycle: 현재 개발 계획과 단계별 직접 evidence 기록. 정책 source-of-truth는 `AGENTS.md`,
> 제품 잔여 순서는 `docs/development-backlog.md`이며 이 문서는 둘을 대체하지 않습니다.

**Goal:** REVIEW3의 과장된 source/evidence 경계를 교정하고, semantic closure, persistence,
exact UI/Policy v4, long-run evidence, self-contained acceptance를 실제 독립 consumer 기준으로
재구축합니다.

**Boundary:** public API, EventRecord, WebRTC/SSE/WS metadata, RTSP/WebRTC media path,
Auth/Role/Scope 계약을 변경하지 않습니다. 사용자는 2026-07-12 최신 지시에서 50~63 완료 뒤
64번 actual refactor를 v3.9.0 현재 branch에서 실행하고 v4.0.0 이관을 취소했습니다. 64번은
승인됐지만 아직 `not-executed`이며, 50~63과 각 preserved contract gate가 닫히기 전 시작하지
않습니다. 64번 뒤 65번 current independent acceptance를 실행합니다.
