## alpha.1 비범위

다음 항목은 v1.1.0 live-only 방향 안의 후속 phase일 수 있지만,
alpha.1 `Live-only 제품 경계 확정` 완료 범위에는 포함하지 않습니다.

- ONVIF import API skeleton 구현
- SourceRegistry optional `origin` schema 구현 또는 migration
- `/ops/sources` health badge UI 구현
- Event POST/WebRTC/SSE/WS smoke matrix 구현
- Scenario timeline state-dump extension 구현
- C++ 기능 로직 변경
- API schema, Event POST payload, WebRTC DataChannel schema,
  SSE/WS metadata schema 변경
- RTSP/WebRTC media path 변경
- 장시간 soak 또는 `verify-predev`
- push

## 검증

문서 변경 최소 검증:

```bash
git diff --check -- README.md README.en.md docs
./server.sh verify-docs-links
```

README 또는 UI asset 참조가 바뀐 경우:

```bash
./server.sh verify-docs-ui-assets
```

비범위 키워드 점검:

```bash
rg -n -i \
  'vms|nvr|long-term recording|장기 녹화|mp4 recorder|video archive|playback|영상 검색|profile g|recorded evidence api|onvif conformant server|full onvif vms' \
  README.md README.en.md docs
```

검색 hit는 [v1.1.0 Boundary Keyword Checks](./v1.1.0-boundary-checks.md)의
허용/재검토/실패 기준으로 분류합니다.
