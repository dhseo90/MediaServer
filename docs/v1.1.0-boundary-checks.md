# v1.1.0 Boundary Keyword Checks

이 문서는 v1.1.0 live-only 제품 경계가 문서에서 흐려지지 않도록
비범위 키워드 정적 점검 기준을 정의합니다.

정적 검색은 자동 판정이 아니라 review 보조입니다. 검색 hit는 문맥에 따라
`허용`, `재검토`, `실패`로 분류합니다.

## 대상 키워드

우선 점검 키워드:

- `VMS`
- `NVR`
- `recording`
- `장기 녹화`
- `MP4 recorder`
- `video archive`
- `playback`
- `영상 검색`
- `Profile G`
- `recorded evidence API`
- `ONVIF conformant server`
- `full ONVIF VMS`

```bash
  README.md README.en.md docs
```

## 허용

다음 문맥의 hit는 허용합니다.

- [v1.1.0 Roadmap](./v1.1.0-roadmap.md)의 제외 범위
- [v1.1.0 Live-only Glossary](./v1.1.0-glossary.md)의 non-goal terms
- versioning/release/distribution policy의 비포함 범위
- history 문서의 과거 작업 기록
- `short event evidence`, `debug/developer`, `default-off`, `보류`,
  `비범위`, `별도 제품 phase`를 같은 문단에서 명시한 설명

## 재검토

다음 문맥의 hit는 사람이 다시 읽어야 합니다.

- README/README.en.md 첫 소개, 한눈에 보기, 문서 로드맵
- release note, milestone, backlog 현재 상태 요약
- `/ops`, `/client` visible text 설명
- 구현 후보 문서 제목이나 완료 상태 표기
- `evidence`, `archive`, `retention`이 중심 기능처럼 쓰인 문장

재검토 결과, 같은 문단에서 비범위/보류/default-off/short event evidence가
명확하면 허용할 수 있습니다.

## 실패

다음 문맥의 hit는 수정 전까지 실패로 봅니다.

- v1.1.0이 VMS/NVR/장기 녹화/playback/search를 제공한다고 읽히는 문장
- ONVIF Profile G recording/replay를 v1.1.0 구현 범위로 둔 문장
- EventRecord/snapshot/clip을 주요 integration contract나 장기 보관 제품으로
  설명한 문장
- client/viewer 화면에 source URL, ONVIF endpoint, raw JSON, debug diagnostics를
  노출한다고 설명한 문장
- 구현하지 않은 API/UI/schema 변경을 완료로 표현한 문장

문서 수정 후 최소 검증:

```bash
git diff --check -- README.md README.en.md docs
./server.sh verify-docs-links
```

## server.sh 검증 명령

아래 명령은 README/README.en/docs의 v1.1.0 live-only 제품 경계 키워드를
정적 점검합니다.

```bash
./server.sh verify-v1.1-boundary-keywords
```

동작:

- 위 기본 검색의 키워드와 client/source/debug 노출 금지 키워드를 스캔
- README/README.en/docs를 대상으로만 검사
- hit를 자동 실패로 처리하지 않고 allow/review/fail 분류 report 생성
- `docs/v1.1.0-roadmap.md`, `docs/v1.1.0-glossary.md`,
  `docs/v1.1.0-boundary-checks.md`, version/release policy, history 문서의
  비범위 설명은 allow 후보로 표시
- README 첫 소개, release note, backlog 현재 상태, UI visible text 설명의 hit는
  review 후보로 표시
- failure 후보가 있으면 non-zero exit
