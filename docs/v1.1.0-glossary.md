# v1.1.0 Live-only Glossary

이 문서는 v1.1.0 live-only 제품 경계를 설명할 때 사용하는 한국어/영어
용어를 고정합니다. UI/API의 machine-readable enum, event payload,
schema field 이름은 번역하지 않습니다.

## Core Terms

| 한국어 표현 | English term | 사용 기준 |
| --- | --- | --- |
| live-only 제품 경계 | live-only product boundary | v1.1.0이 녹화/VMS/NVR로 확장하지 않는다는 최상위 기준 |
| live media relay | live media relay | RTSP/WebRTC live stream 중계 역할 |
| live source onboarding | live source onboarding | 운영자가 live source를 등록/검증/노출 준비하는 흐름 |
| ONVIF camera import | ONVIF camera import | ONVIF camera를 찾아 live RTSP source로 등록하는 기능 |
| ONVIF-assisted live source onboarding | ONVIF-assisted live source onboarding | ONVIF를 live source 등록 보조 수단으로 쓸 때 |
| live source health | live source health | 현재 source의 도달성, stale/offline, reconnect 상태 |
| operator workflow | operator workflow | 운영자가 `/ops`에서 상태 확인과 다음 조치를 수행하는 흐름 |
| live VA event | live VA event | 저장 영상 분석이 아니라 live stream에서 발생하는 VA event |
| runtime metadata | runtime metadata | dashboard, DataChannel, SSE/WS가 소비하는 현재 분석 상태 |
| live event delivery contract | live event delivery contract | Event POST/WebRTC/SSE/WS의 live event/metadata 소비 계약. 기존 schema 식별자와 검증 기준을 고정하는 문서 계약 |
| short event evidence | short event evidence | EventRecord/snapshot/clip frame bundle 같은 짧은 이벤트 맥락 보조 |
| sanitized client state | sanitized client state | viewer/client에 source locator나 raw debug 없이 제공하는 요약 상태 |

## Non-goal Terms

아래 표현은 v1.1.0 제품 설명의 중심 문구로 쓰지 않습니다.
필요하면 같은 문단에서 `비범위`, `보류`, `default-off`, `debug/developer`,
`short event evidence` 중 하나의 상태를 함께 씁니다.

| 피해야 할 중심 표현 | 허용되는 설명 방식 |
| --- | --- |
| VMS | v1.1.0 비범위, 별도 제품 phase |
| NVR | v1.1.0 비범위, 별도 제품 phase |
| long-term recording | v1.1.0 비범위 |
| 장기 녹화 | v1.1.0 비범위 |
| MP4 recorder | v1.1.0 비범위, 별도 보관/개인정보 policy gate 필요 |
| video archive | v1.1.0 비범위 |
| playback timeline | v1.1.0 비범위 |

## Translation Rules

- `ONVIF`, `RTSP`, `WebRTC`, `WHEP`, `WHIP`, `SSE`, `WebSocket`,
  `Event POST`, `DataChannel`, `SourceRegistry`, `PublishedView`,
  `EventRecord`, `vaRule`은 원문 표기를 유지합니다.
- `live`는 저장/재생과 구분해야 하므로 한국어 문서에서도 필요하면 원문을 유지합니다.
- `evidence`는 장기 보관 증거처럼 들릴 수 있으므로 v1.1.0에서는
  `short event evidence` 또는 `짧은 이벤트 증거/맥락 보조`로 씁니다.
- `source health`는 저장 영상 health가 아니라 live source 도달성과 stale/offline
  상태를 뜻합니다.
- `metadata contract`는 API schema 변경 약속이 아니라 기존 contract의 문서화와
  검증 기준 정리를 뜻합니다.
- UI visible text는 operator/client가 이해하기 쉬운 문구를 우선하고,
  machine-readable 값은 번역하지 않습니다.

## Examples

권장:

- v1.1.0은 ONVIF-assisted live source onboarding을 다룹니다.
- EventRecord/snapshot/clip은 short event evidence 보조 기능입니다.
- Client dashboard는 sanitized live source health만 표시합니다.

비권장:

- v1.1.0은 ONVIF VMS를 제공합니다.
- EventRecord API를 recorded evidence integration contract로 사용합니다.
- `/client` 화면에 RTSP source URL과 raw debug JSON을 표시합니다.
