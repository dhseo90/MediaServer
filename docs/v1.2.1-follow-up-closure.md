# v1.2.1 Follow-up Closure

이 문서는 v1.2.1 roadmap 완료 후 남은 후속 항목을 다시 분류합니다.
목표는 새 product scope를 열지 않고, 로드맵 안에서 더 개발할 항목이 남았는지
명확히 판단하는 것입니다.

## 기준

- v1.2.1 roadmap 범위는 문서/version drift, release close-out 자동화, flaky
  검증, UI 수동 검수 보강, Re-ID/ONVIF wording guard, dependency/artifact
  housekeeping입니다.
- schema, Event POST payload, WebRTC DataChannel, SSE/WS metadata,
  RTSP/WebRTC media path, auth/session contract는 변경하지 않습니다.
- 실제 tag, push, GitHub Release 생성은 수행하지 않습니다.
- 장시간 soak, `verify-predev`, 실장비 ONVIF field smoke, 외부 TURN/WHEP,
  실제 YouTube URL relay는 명시 요청이나 외부 선행조건 없이는 실행하지 않습니다.

## 후속 항목 판정

| 항목 | 판정 | 근거 | 남은 개발 이슈 |
| --- | --- | --- | --- |
| Release 직전 GitHub Actions 상태 확인 | release 운영 gate | `verify-release-closeout-helper`는 dry-run으로 tag/push/GitHub Release를 수행하지 않고 수동 확인 항목으로 남깁니다. Actions 최신 상태는 로컬 개발 완료 근거로 쓰지 않습니다. | 없음 |
| Auth-on manual release rehearsal | 선택 release rehearsal | `verify-auth-bootstrap`, `verify-auth-users`, `verify-auth-routes`, `verify-manual-ui-evidence`가 setup/login/role/scope 경계를 확인합니다. 별도 브라우저 수동 제출은 release rehearsal 때 throwaway users file로 수행합니다. | 없음 |
| ONVIF 실장비 field smoke | 외부 장비/credential gate | v1.2.1은 field smoke readiness와 redaction/failure wording을 닫았습니다. 실제 장비 endpoint 성공은 no-device suite 통과로 대체하지 않습니다. | 없음 |
| Re-ID field sample 반복 관찰 | 별도 research/default-on review | `verify-reid-advanced-tracking`과 `compare-close-object-tracker` 출력은 `matrix-ok`와 제품 default-on 결정을 분리합니다. Re-ID default-on은 v1.2.1 비범위입니다. | 없음 |
| UI visual baseline 승인 기록 | release/RC evidence gate | `verify-ui-visual-artifact-index`와 approval template은 존재합니다. baseline 채택은 수동 승인 기록이며 public release asset이 아닙니다. | 없음 |

## 결론

- 로드맵 내 개발 가능한 후속 이슈: 없음.
- 남은 항목은 release 운영 gate 또는 외부 선행조건 gate입니다.
- 미확인 항목을 통과로 쓰지 않습니다.
- 다음 release cut에서는 `verify-release-closeout-helper` 리포트와 GitHub Actions
  상태를 함께 확인합니다.
