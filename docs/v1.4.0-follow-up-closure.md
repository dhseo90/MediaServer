# v1.4.0 Follow-up Closure

이 문서는 v1.4.0 tracker/Re-ID roadmap 구현 이후 추천된 후속 항목을 다시
분류하고, v1.4.0 범위 안에서 개발 가능한 항목을 모두 닫았는지 기록합니다.

## 기준

- v1.4.0은 rule-level tracker/Re-ID opt-in, privacy/runtime fallback gate,
  Kalman-lite, ByteTrack, Re-ID assist, OC-SORT/BoT-SORT/DeepSORT boundary를
  다룹니다.
- 제품 default tracker 변경, Re-ID/ByteTrack default-on, 실제 Re-ID model bundle,
  customer/field 영상 보존 자동화, dataset ingest, post-v1.4 benchmark는 범위
  밖입니다.
- Event POST, WebRTC DataChannel, SSE/WS metadata schema, RTSP/WebRTC media path,
  auth/session contract를 변경하지 않습니다.
- 장시간 soak, `verify-predev`, push, tag, GitHub Release는 명시 요청 없이는
  실행하지 않습니다.

## 후속 항목 판정

| 항목 | v1.4.0 판정 | 처리 | 남은 개발 이슈 |
| --- | --- | --- | --- |
| ByteTrack default-on field evidence review | 별도 Phase gate | v1.4.0은 `tracker=bytetrack` rule-level opt-in까지입니다. fixture matrix의 candidate/review-required 결과는 제품 default-on 완료가 아니며 별도 field evidence review로 남깁니다. | 없음 |
| Re-ID assist warning trend tracking | v1.4.0 안정화 완료 | 단일 `compare-close-object-tracker --history-dir`가 summary/report/index를 누적하고 warning reason count, recommendation, `defaultOnCandidate`를 보존합니다. | 없음 |
| field-driving fixture report archive policy | v1.4.0 마무리 완료 | [Close-object Report Archive Policy](./close-object-report-archive-policy.md)에서 summary/report/history index만 evidence로 보존하고 raw media/image/customer/source/auth/model material은 제외합니다. | 없음 |
| tracker warning dashboard summary | v1.4.0 UI 안정화 완료 | Ops Dashboard 트래킹 이슈 그룹은 issue type, track list, class, association, overlap, missed, direction count, 샘플 message와 “default-on 근거 아님” 경계를 함께 표시합니다. | 없음 |
| post-v1.4 OC-SORT benchmark issue | 별도 Phase gate | v1.4.0에서는 OC-SORT를 runtime tracker로 추가하지 않는 boundary와 verifier만 유지합니다. 실제 benchmark는 post-v1.4 후보입니다. | 없음 |

## 추가 후속 항목 점검

2026-05-18 KST 기준 v1.4.0 close-out 범위 안에서 추가 개발로 닫아야 하는 후속 이슈는
남기지 않습니다.

추가로 확인한 경계:

- ByteTrack/Kalman-lite/Re-ID assist는 rule-level opt-in입니다.
- close-object matrix 또는 comparison history는 evidence이며 제품 default-on 승인
  값이 아닙니다.
- field-driving report archive는 summary/report/index만 보존합니다.
- 고객/현장 영상, raw frame, crop, embedding, model path/checksum/provenance,
  source URL, credential, auth/session 파일은 archive/release asset에 포함하지
  않습니다.
- UI screenshot 산출물은 기존 UI visual artifact policy를 따르며 close-object
  history dir에 섞지 않습니다.
- OC-SORT, BoT-SORT, DeepSORT 실제 구현과 benchmark는 이 closure에서 수행하지
  않습니다.

## 결론

- v1.4.0 로드맵 안의 개발 가능한 후속 이슈: 없음.
- 남은 항목은 제품 default-on review, field evidence review, post-v1.4 benchmark
  같은 별도 Phase gate입니다.
- 미확인 항목을 통과로 쓰지 않습니다.
- 푸시는 명시 요청 전까지 수행하지 않습니다.
