# v1.5.0 Follow-up Closure

이 문서는 v1.5.0 Tracker/Re-ID opt-in 안정화 roadmap 구현 이후 남은 후속
항목을 다시 분류하고, v1.5.0 범위 안에서 개발 가능한 항목을 모두 닫았는지
기록합니다.

## 기준

- v1.5.0은 v1.4.0의 rule-level tracker/Re-ID opt-in 경계를 유지하면서 명시
  opt-in guard, stability matrix, Re-ID provenance/fallback approval, Ops warning
  next-action, audit export review, field smoke summary evidence boundary,
  OC-SORT experimental sandbox를 다룹니다.
- 제품 default tracker/Re-ID 변경, global/default-on, 기존 rule/source/profile
  자동 migration, 실제 Re-ID model/runtime bundle, OC-SORT runtime tracker 승격,
  field sample 기반 tracker replacement product review는 범위 밖입니다.
- Event POST, WebRTC DataChannel, SSE/WS metadata schema, RTSP/WebRTC media path,
  auth/session contract를 변경하지 않습니다.
- 장시간 soak, `verify-predev`, push, tag, GitHub Release는 명시 요청 없이는
  실행하지 않습니다.

## 후속 항목 판정

| 항목 | v1.5.0 판정 | 처리 | 남은 개발 이슈 |
| --- | --- | --- | --- |
| Explicit opt-in tracker/Re-ID policy guard | v1.5.0 완료 | rule-level `analysis.trackingPolicy`만 적용하고 tracker 없는 Re-ID assist, global/default-on, 자동 migration을 저장/runtime/UI/docs guard로 차단합니다. | 없음 |
| Tracker/Re-ID stability matrix | v1.5.0 안정화 완료 | `lite/off`, `kalman-lite/off`, `bytetrack/off`, `lite/assist`, `kalman-lite/assist`, `bytetrack/assist` 조합을 warning drift 관찰 matrix로 고정하고, `matrix-ok`와 default-on 판단을 분리합니다. | 없음 |
| Re-ID opt-in model provenance and fallback approval | v1.5.0 gate 완료 | Re-ID assist는 명시 opt-in 상태에서도 provenance/checksum/privacy/retention 조건이 없으면 NoOp fallback으로 닫고 model/source material을 외부 metadata나 client/viewer에 노출하지 않습니다. | 없음 |
| Ops Dashboard tracker warning next-action refinement | v1.5.0 UI 안정화 완료 | tracker/Re-ID warning은 사용자 opt-in 튜닝 참고와 다음 조치로 표시하고 default-on 근거가 아님을 Ops copy와 fixture로 고정합니다. | 없음 |
| Audit export review hardening | v1.5.0 감사 UX 강화 완료 | Tracker/Re-ID 설정 변경 review chip과 model/fallback status-only 표시를 유지하고 조회/JSON/CSV/Diff JSON export에서 model/source/auth/raw material을 재마스킹합니다. | 없음 |
| Field smoke summary evidence boundary | v1.5.0 evidence 경계 완료 | `compare-close-object-tracker --history-dir` 산출물은 summary/report/history index evidence만 보존하고 raw media, crop, embedding, model/source/auth material은 제외합니다. | 없음 |
| OC-SORT experimental sandbox | v1.5.0 P2 sandbox 완료 | OC-SORT는 `--experimental-sandbox oc-sort` manifest-only 비교 metadata로만 기록하며 runtime tracker policy, Ops Rules 선택값, schema/media path에는 추가하지 않습니다. | 없음 |

## 추가 후속 항목 점검

2026-05-19 KST 기준 v1.5.0 close-out 범위 안에서 추가 개발로 닫아야 하는 후속
이슈는 남기지 않습니다.

추가로 확인한 경계:

- Tracker/Re-ID는 rule-level 명시 opt-in입니다.
- tracker warning, fixture matrix, field-like summary evidence는 default-on 승격
  근거가 아닙니다.
- Re-ID model path/checksum/provenance, crop, embedding, raw field media,
  credential/auth/session material은 client/viewer, public docs, release asset,
  history evidence에 포함하지 않습니다.
- actual OC-SORT algorithm adapter and dataset benchmark report,
  OC-SORT/BoT-SORT/DeepSORT 실제 algorithm adapter는 이 closure에서 수행하지
  않습니다.
- field sample history review workflow, tracker experimental benchmark harness,
  ONVIF field smoke evidence reconciliation, release evidence dashboard cleanup은 별도
  Phase gate입니다.

## 결론

- v1.5.0 로드맵 안의 개발 가능한 후속 이슈: 없음.
- 남은 항목은 tracker replacement product review, runtime/model bundle RC policy,
  field evidence reconciliation 같은 별도 Phase gate입니다.
- 미확인 항목을 통과로 쓰지 않습니다.
- 푸시는 명시 요청 전까지 수행하지 않습니다.
