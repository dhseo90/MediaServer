# v1.6.0 Audit Export Masking Regression Hardening

이 문서는 V160-P1-02 `Audit/export masking regression hardening`의 기준입니다.
목표는 `/ops/api/audit` 조회와 JSON/CSV/Diff JSON export가 source/model/auth/raw
material을 다시 노출하지 않도록 v1.6.0 release guard에 고정하는 것입니다.

## Guard 경계

- 저장 시점과 조회 시점 모두 `RedactAuditJsonFragment`를 거치며, query/export 결과는
  redacted record를 기준으로 필터링합니다.
- JSON export, CSV export, Diff JSON export는 같은 redacted entry set을 사용합니다.
- masking 대상은 source URL/URI/file, endpoint/stream URI,
  model path/checksum/provenance, raw media/frame, crop, embedding,
  password/token/hash/secret/credential/capability material입니다.
- Ops UI는 Tracker/Re-ID 변경과 model/fallback status-only review chip을 표시할 수
  있지만, model/source/auth/raw material 원문을 표시하지 않습니다.
- client/viewer surface에는 audit export controls, raw JSON, source/debug/model/auth
  material을 노출하지 않습니다.

## 비노출 예시

| 입력 후보 | export 표시 |
| --- | --- |
| `rtsp://...`, `sourceUrl`, `streamUri` | `[redacted]` |
| `models/reid.onnx`, `modelSha256`, `modelProvenance` | `[redacted]` |
| `passwordHash`, `tokenHash`, `credentialRef`, `capabilityToken` | `[redacted]` |
| `rawMedia`, `rawFrame`, `crop`, `embedding` | `[redacted]` |

## 후속 분류

- 미분류 P0~P1 후속 이슈: 없음. 이번 항목의 masking drift 위험은
  `verify-v160-audit-export-masking-regression-hardening`과 기존
  `verify-v150-audit-export-review-hardening`, `verify-ops-audit-trail`로 닫습니다.
- V160-P1-03 Runtime/model bundle RC policy와 V160-P1-04 Manual UI release checklist
  closure는 같은 v1.6.0 안정화 페이즈의 별도 항목이므로 이 문서에서 구현 완료로
  판정하지 않습니다.
- V160-P2-01~V160-P2-02와 별도 Phase 후보는 이 audit/export 항목의 즉시 구현
  후속으로 끌어오지 않습니다.
