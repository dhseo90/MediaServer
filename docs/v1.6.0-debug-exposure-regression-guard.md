# v1.6.0 Client/Ops Debug Exposure Regression Guard

이 문서는 V160-P0-03 `Client/Ops debug exposure regression guard`의 기준입니다.
목표는 viewer/client 화면과 client scoped API에 source URL, raw JSON, debug counter,
rule/profile editor, model/source/auth material이 노출되지 않도록 기존 smoke와
정적 guard를 강화하는 것입니다.

## Guard 대상

| 범주 | viewer/client 금지 예 |
| --- | --- |
| Source material | `sourceUrl`, `sourceUri`, `rtspUrl`, `httpUrl`, `whepUrl`, `storagePath`, `file://`, `rtsp://`, `rtsps://` |
| Debug material | raw JSON, raw diagnostic, `debugCounters`, `debugSummary`, `analysisTapId`, BBox diagnostics, Developer URL |
| Rule/Profile material | `opsVaRuleForm`, `opsEventRuleForm`, `opsProfileForm`, `/ops/api/sources`, `/ops/api/views`, `/lab/analysis/taps` |
| Model/identity material | `modelPath`, `modelSha256`, `modelChecksum`, `modelProvenance`, `modelUrl`, `crop`, `embedding`, `appearanceCrop`, `appearanceEmbedding` |
| Auth/session material | `passwordHash`, `passwordHistory`, `tokenHash`, `sessionToken`, `credentialRef`, capability/token material |

## 구현 기준

- `verify-ops-client-ui`는 client page HTML, rendered DOM, clipboard text, scoped API
  JSON key traversal을 함께 검사합니다.
- client scoped API는 PublishedView wrapper만 사용하고 generic source/session/debug
  route를 노출하지 않습니다.
- Ops 화면에는 운영자용 debug/details가 남을 수 있지만, raw JSON은 운영자 debug
  details 접힘 영역에만 둡니다.
- client/viewer 화면에는 Ops/Lab navigation, source/rule/profile editor, model/source
  material, auth/session material을 노출하지 않습니다.
- removed UI route(`/lab`, `/lab/rules`, `/lab/import`, `/webrtc/test`)는 닫힌 상태를
  유지합니다.
- Event POST, WebRTC DataChannel, SSE/WS metadata schema, RTSP/WebRTC media path는
  이 guard 작업에서 변경하지 않습니다.

## 후속 분류

- 미분류 P0~P1 후속 이슈: 없음. 이번 항목에서 발견한 client redaction guard 빈칸은
  forbidden text/key matrix와 `verify-v160-debug-exposure-regression-guard`로 닫습니다.
- V160-P0-04는 같은 P0 안정화 페이즈의 별도 항목이므로 이 작업에서 구현 완료로
  판정하지 않습니다.
- V160-P1-02 audit/export masking regression hardening은 별도 P1 항목이며, 이 작업의
  즉시 구현 후속으로 끌어오지 않습니다.
- P1/P2 및 별도 Phase 후보는 V160-P0-03의 즉시 후속 이슈로 끌어오지 않습니다.
