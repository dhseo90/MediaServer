# v1.6.0 ONVIF Field Smoke Evidence Reconciliation

이 문서는 V160-P1-01 `ONVIF field smoke evidence reconciliation`의 기준입니다.
목표는 실장비 성공 보장이 아니라 기존 ONVIF field smoke gate, redacted sample
bundle, release evidence dashboard가 같은 상태 언어로 field evidence를 기록하게
하는 것입니다.

## Evidence 경계

- `verify-onvif-no-device-suite` 통과는 parser, fixture, loopback, redaction 개발
  검증입니다. 이것을 실제 field smoke `PASS`나 `realDeviceEndpointSuccess=pass`로
  쓰지 않습니다.
- 실제 장비를 사용하지 않았으면 `gateDecision=not-run`,
  `realDeviceTestPerformed=false`, `realDeviceEndpointSuccess=unverified`,
  `playbackStatus=skipped`로 기록합니다.
- 실제 장비 결과가 있어도 endpoint, credential, RTSP/RTSPS playback URL, raw SOAP,
  HTTP header, raw diagnostic JSON, auth/session material은 공유 evidence에
  포함하지 않습니다.
- field evidence는 redacted summary/report/history index와 sample bundle review
  상태만 release evidence dashboard에 연결합니다.
- GitHub Actions, tag, push, GitHub Release, 외부 현장 승인 링크는 없으면
  `UNVERIFIED`로 유지합니다.

## Dashboard 연결

`v1.6.0 Release Evidence Dashboard`에서는 ONVIF field smoke를 longrun/external
gate와 같은 방식으로 다룹니다.

| 상태 | release evidence 기록 |
| --- | --- |
| 실장비 미실행 | `NOT RUN`, no-device suite 결과와 분리 |
| 실장비 실행 실패 | `FAIL`, sanitized failure reason만 기록 |
| 실장비 실행 통과 | `PASS`, redaction artifact review와 report review가 함께 통과한 경우만 기록 |
| 외부 승인/Actions 링크 없음 | `UNVERIFIED` |

## 보존 가능 산출물

- `gateDecision`, `realDeviceTestPerformed`, `realDeviceEndpointSuccess`,
  `playbackStatus`, `redactionArtifactReview`, `fieldSmokeReportReview`
- `endpointRedacted=true`, `streamUriRedacted=true`, `rawSoapIncluded=false`,
  `plaintextSecretIncluded=false`
- `credentialRef present, plaintext omitted`
- `clientRedaction`, `opsCopyParity`, `probeErrorWording`
- sanitized summary/report/history index

## 보존 금지 산출물

- endpoint URL, source URL/URI/file, RTSP/RTSPS stream URI
- username, password, token, credential reference 실제 값, auth/session material
- raw SOAP, HTTP headers, raw diagnostic JSON, raw media, raw frame
- crop, embedding, model path/checksum/provenance

## 후속 분류

- 미분류 P0~P1 후속 이슈: 없음. 이번 항목의 잔여 위험은 field smoke evidence
  reconciliation 문서와 `verify-v160-onvif-field-smoke-evidence-reconciliation`로
  닫습니다.
- V160-P1-02 Audit/export masking regression hardening, V160-P1-03 Runtime/model
  bundle RC policy, V160-P1-04 Manual UI release checklist closure는 같은 v1.6.0
  안정화 페이즈의 별도 항목이므로 이 문서에서 구현 완료로 판정하지 않습니다.
- V160-P2-01~V160-P2-02와 별도 Phase 후보는 이 field evidence 항목의 즉시 구현
  후속으로 끌어오지 않습니다.
