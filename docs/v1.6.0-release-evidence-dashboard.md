# v1.6.0 Release Evidence Dashboard

이 문서는 V160-P0-01 `Release evidence dashboard cleanup`의 기준입니다.
v1.6.0은 새 제품 기능을 여는 release가 아니라, v1.5.0까지 닫은 source-only
제품 범위를 안정화하는 release입니다. 따라서 이 dashboard는 실행한 검증, 미실행
검증, 외부 gate, PR/Actions 확인 상태를 한곳에서 분리해 추적합니다.

## Evidence 원칙

- 확인된 명령만 `PASS` 또는 `FAIL`로 기록합니다.
- 실행하지 않은 장시간 soak, 실장비 ONVIF field smoke, YouTube real URL relay,
  외부 TURN/WHEP credential 운영 검증은 `NOT RUN`으로 남깁니다.
- GitHub Actions, tag, push, GitHub Release는 로컬 검증 결과와 분리하고 링크가
  없으면 `UNVERIFIED`로 남깁니다.
- release evidence에는 source URL, credential, auth/session material, raw media,
  raw diagnostic JSON, crop, embedding, model path/checksum/provenance를 포함하지
  않습니다.
- Event POST, WebRTC DataChannel, SSE/WS metadata schema, RTSP/WebRTC media path는
  이 dashboard 작업에서 변경하지 않습니다.

## 후속 분류

- 미분류 P0~P1 후속 이슈: 없음. 이번 항목에서 발견한 evidence drift 위험은
  dashboard 문서, verifier, docs index 연결로 닫습니다.
- V160-P0-02~V160-P0-04는 같은 P0 안정화 페이즈의 별도 항목이므로 이 문서에서
  구현 완료로 판정하지 않습니다.
- V160-P1-01~V160-P1-04, V160-P2-01~V160-P2-02, 별도 Phase 후보는 이 evidence
  dashboard의 즉시 구현 후속으로 끌어오지 않습니다.
