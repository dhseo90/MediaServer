# v1.6.0 Runtime/Model Bundle RC Policy

이 문서는 V160-P1-03 `Runtime/model bundle RC policy`의 기준입니다.
v1.6.0은 runtime/model bundle을 release asset에 포함하지 않습니다. 이 항목의
목표는 향후 별도 RC에서 runtime/model 포함 배포를 검토할 때 필요한 승인 조건과
차단 기준을 고정하는 것입니다.

## 기본 판정

- v1.6.0 기본 release는 source/doc 중심입니다.
- FFmpeg, FFprobe, libav*, x264/x265, GStreamer GPL-risk plugin, ONNX Runtime package,
  YOLO/Re-ID/model binary는 기본 release asset에 포함하지 않습니다.
- Re-ID opt-in model은 model path/checksum/provenance가 명시되고 검증을 통과할 때만
  runtime에서 사용 후보가 되며, missing/invalid/mismatched model은 NoOp fallback으로
  닫습니다.
- model path/checksum/provenance, crop, embedding, appearance profile은 Event POST,
  WebRTC DataChannel, SSE/WS metadata, client/viewer surface에 노출하지 않습니다.
- runtime/model bundle RC는 source-only release와 별도 후보입니다.
  tag, push, GitHub Release, binary upload는 수동 승인 전까지 수행하지 않습니다.

## 향후 RC 필수 조건

runtime/model을 의도적으로 포함하는 별도 RC는 아래 evidence를 모두 갖춘 경우에만
검토할 수 있습니다.

| 영역 | 필수 evidence |
| --- | --- |
| Bundle policy | `verify-bundle-policy --bundle-dir <release_bundle_dir>` JSON report, risky runtime hit 여부 |
| Dry-run shape | `verify-release-bundle-dry-run` candidate summary, negative fixture 차단 결과 |
| Source offer | `source-offer-checklist --stable --bundle-policy-report <report.json>` |
| License/attribution | upstream license text, attribution, local build config, configure flags |
| Model provenance | model card 또는 동등 provenance, checksum manifest, redistribution license |
| Privacy/redaction | crop/embedding/model path/checksum/provenance 비노출 review |
| Release evidence | 실행/미실행/미확인, 외부 승인 링크, Actions status 분리 |

## 차단 기준

- bundle policy report가 `fail`인데 `--allow-risky-runtime` 없이 기본 release에 포함
- ONNX Runtime package, YOLO/Re-ID/model binary를 source-only release asset에 업로드
- model card/license/checksum/provenance 없이 model binary 포함
- source URL, credential/auth/session material, customer media, raw frame, crop,
  embedding, logs, auth store, snapshot, evidence bundle 포함
- Event POST/WebRTC DataChannel/SSE/WS metadata schema 변경 또는
  RTSP/WebRTC media path 변경을 bundle policy 항목에 섞기
- tracker/Re-ID default-on, product default tracker 변경, runtime tracker 승격을
  bundle RC 검토 완료로 과장

## 후속 분류

- 미분류 P0~P1 후속 이슈: 없음. 이번 항목의 runtime/model bundle drift 위험은
  `verify-v160-runtime-model-bundle-rc-policy`, `verify-v150-reid-provenance-fallback-approval`,
  `verify-bundle-policy`로 닫습니다.
- V160-P1-04 Manual UI release checklist closure는 같은 v1.6.0 안정화 페이즈의
  별도 항목이므로 이 문서에서 구현 완료로 판정하지 않습니다.
- V160-P2-01~V160-P2-02와 별도 Phase 후보는 이 runtime/model bundle 항목의 즉시
  구현 후속으로 끌어오지 않습니다.
