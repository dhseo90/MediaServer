# v1.6.0 Tracker/Re-ID Opt-in Stabilization Close-out

이 문서는 V160-P0-04 `Tracker/Re-ID opt-in stabilization close-out`의 기준입니다.
목표는 v1.5.0까지 닫은 rule-level tracker/Re-ID opt-in을 v1.6.0 stabilization
release에서 default-off 안정화 상태로 닫고, default-on 승격이나 runtime/model
bundle release와 분리하는 것입니다.

## Close-out 기준

| 항목 | v1.6.0 판정 |
| --- | --- |
| Rule-level opt-in | 사용자가 rule/vaRule에서 명시 선택한 `analysis.trackingPolicy.tracker`와 `analysis.trackingPolicy.reid`만 적용합니다. |
| Legacy rule fallback | `trackingPolicy`가 없는 기존 rule은 runtime에서 `tracker=lite`, `reid=off`, `source=rule-default`로 해석하며 저장 문서를 자동 migration하지 않습니다. |
| Tracker/Re-ID matrix | `lite/off`, `kalman-lite/off`, `bytetrack/off`, `lite/assist`, `kalman-lite/assist`, `bytetrack/assist` 조합은 opt-in 품질 참고 matrix입니다. |
| Re-ID model provenance | missing/invalid/mismatched model, checksum/provenance 누락, ONNX Runtime 미지원은 `NoOp fallback`으로 닫습니다. |
| External metadata | Event POST, WebRTC DataChannel, SSE/WS metadata, client/viewer 화면에는 crop, embedding, model path/checksum/provenance를 노출하지 않습니다. |
| Default-on decision | v1.6.0에서는 tracker default-on, Re-ID default-on, product default tracker 변경을 승인하지 않습니다. |
| Runtime/model bundle | 실제 Re-ID model/runtime/binary bundle release, model card, dataset provenance package는 v1.6.0 범위가 아닙니다. |

## 연결 verifier

```bash
./server.sh verify-v160-tracker-reid-opt-in-closeout
./server.sh verify-v150-follow-up-closure
./server.sh verify-v150-tracker-reid-stability-matrix
./server.sh verify-v150-reid-provenance-fallback-approval
```

위 명령은 v1.6.0 P0 close-out에서 v1.5.0 carry-over 상태를 확인하는 gate입니다.
`verify-tracker-stability` 조합 실행과 `compare-close-object-tracker --fixture-matrix`는
실행한 경우에만 evidence로 기록합니다. 실행하지 않으면 NOT RUN으로 남깁니다.

## P0 stabilization follow-up closure

v1.6.0 P0 안정화 페이즈는 다음 네 항목으로만 닫습니다.

- V160-P0-01 Release evidence dashboard cleanup
- V160-P0-02 Stability verification gate cleanup
- V160-P0-03 Client/Ops debug exposure regression guard
- V160-P0-04 Tracker/Re-ID opt-in stabilization close-out

미분류 P0~P1 후속 이슈: 없음. 이번 페이즈에서 발견한 P0/P1 빈칸은 release
evidence dashboard, stability gate, client debug exposure guard, tracker/Re-ID
opt-in close-out verifier로 닫습니다.

후속 Phase로 유지:

- V160-P1-01 ONVIF field smoke evidence reconciliation

- V160-P1-03 Runtime/model bundle RC policy

- 별도 기능 개발 Phase 후보
